# 개발 문서 익명화 기록

이 폴더는 2026-11-21 KST 개발 작업 트리의 네 문서를 공개 독자가 열람할 수 있게 보존한 사본이다. 본문의 기술 내용, 명령 형식, 당시 작업 규칙·일정, 역할 구분, 실패·수정·재검증 순서를 유지했다. 각 문서의 머리말에 보관본이라는 표시와 현재 공개 문서로 가는 링크를 추가했다.

| 개발 당시 파일 | 보관 파일 | 공개를 위해 바뀐 내용 |
| --- | --- | --- |
| `README.md` | [README.md](README.md) | 원본 7행의 프로젝트 절대 경로를 프로젝트 루트로, 33행의 엔진 설치 경로 예시를 자리표시자로 치환했다. |
| `AGENTS.md` | [Agent-Workflow-History.md](Agent-Workflow-History.md) | 원본 10행의 프로젝트 절대 경로를 프로젝트 루트로 치환했다. 현재 지침과 구분되는 보관 파일명을 사용했다. |
| `Docs/Design.md` | [Design.md](Design.md) | 본문에 경로·연락처·자격 증명 값의 변경 대상이 없었다. 당시 적용 시점을 설명하는 머리말을 붙였다. |
| `Docs/Status.md` | [Status.md](Status.md) | 원본 3행의 프로젝트 절대 경로를 프로젝트 루트로, 646·672·687·743행의 절대 경로를 프로젝트 상대 경로로 치환했다. |

토큰과 이메일의 실제 값은 보관 대상 본문에서 발견되지 않았다. 보안 검사 기록에 등장하는 `SecurityToken` 설정 이름은 당시 점검 내용을 설명하므로 유지했다. 개인 폴더나 값의 치환 전 문자열은 이 표에 싣지 않았다.

역사 기록 속 빌드 ID·로컬 커밋 식별자와 `Saved/`·`Artifacts/` 참조는 당시 작업에서 사용한 근거를 식별한다. Git 이력, 실행 로그 및 패키지를 이 폴더로 옮긴 범위에는 포함하지 않았다. 현재 내려받을 수 있는 근거는 [공개 검증 자료](../Evidence/README.md)에서 확인할 수 있다.
