# 개발과 검증 기록

## 게임과 구현

- 게임의 목표와 조작, 분신 재생·전투·성장 흐름은 [설계 문서](Design.md)에 정리했다.
- 개발자는 분해장, 분신별 경로 색상, 피격 표시, 강화창 입력 상태 수정, 탄환 ISM 일괄 갱신을 C++로 작업했다. 전투와 난이도 조건을 선택하고 실제 플레이와 Unreal Insights에서 동작을 확인했다.
- Codex는 코드와 설계 리뷰, 게임 기반 구현 지원, 검증 도구 및 리포트 작성, 자동 검사 실행과 결과 대조를 맡았다.

## 강화 전후 분신 공격 회귀

개발자가 검토한 규칙은 과거 공격의 강화 단계가 현재 강화에 의해 바뀌지 않는다는 것이다. Codex는 [EchoGameplayTests.cpp](../Source/EchoAssault/EchoGameplayTests.cpp)의 `EchoAssault.Gameplay.WeaponUpgradeReplayBoundary`에 적용했다.

| 당시 플레이어 발사 | 첫 분신의 경계 | 그 시점까지 분신 탄환 검증 |
| --- | --- | --- |
| 10초, 칼날 1단계 | 18초 | 1단계 6발, 2단계 0발 |
| 13초, 칼날 2단계 | 21초 | 1단계 6발, 2단계 8발 |

슬롯 0은 플레이어, 슬롯 1은 첫 분신이다. 테스트는 지정된 슬롯의 탄환을 당시 단계별로 집계한다. 각 경계 직전과 두 번째 경계의 다음 프레임도 확인한다.

## 인수인계와 QA 사례

개발자가 기존 대화를 전달하지 않은 새 Codex 세션에 시작 문서와 검사 자료를 줬다. 세션은 [PerfCheck.ps1](../Tools/PerfCheck.ps1)을 선택해 기록을 검토하고 실제 1080p 측정을 다시 실행했다. 재실행 `PerfCheck-20261120-010224-535`는 이동·정지 각각 3회 유효였다. 세션에 전달한 세 가지 판정도 원본 기록과 재대조했다.

| 평가 상황 | 판정 근거 | 결과 |
| --- | --- | --- |
| 정상 측정 `004124-569` | 프레임 CSV의 뷰포트·실행별 저장 설정·회차 수 | 1080p 6회 유효 |
| 해상도 불일치 `221257` | 인자는 1920×1080, 저장 설정은 888×500, 실제 뷰포트 열 부재 | 1080p 비교 제외 |
| 최신 실패 `010148-557` | 스테이징 쓰기 권한 오류, 종료 코드 1, 캡처 0회 | 실패 기록과 이전 유효 결과를 구분 |

세 사례의 기대 판정이 모두 재현됐다. [QA 스킬](../.agents/skills/echo-performance-qa/SKILL.md) · [선별 근거](Evidence/QA-Case-Evidence.json)

## 성능 근거

전체 전투 1080p 계측과 별도의 탄환 ISM CPU 실험에 대해 각각 조건, 원본 발췌와 집계를 남겼다. 1080p 측정에는 패키징 전후 입력 지문 비교도 포함했다. [계측 자료](Evidence/README.md)
